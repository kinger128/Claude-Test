# Takes

A songwriting sketchpad that runs in the browser and installs to a phone home screen.

- One-tap recording of ideas
- Multi-track takes with overdub, mute, volume and a metronome count-in
- Lyrics with section markers
- Chord progressions in any key, played back under your takes
- Export a take or the full mix as WAV

Everything is stored on the device (IndexedDB). The app lives in `docs/` and is served by GitHub Pages.
